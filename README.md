# Tampermonkey Scripts

Personal browser userscripts for Tampermonkey.

## Scripts

- `google-calendar-robust-shortcuts.user.js` - Google Calendar sidebar and visible calendar shortcuts.
- `gmail-keyboard-sidebar-shortcuts.user.js` - Gmail sidebar and folder shortcuts.
- `monday-left-pane-shortcuts.user.js` - monday.com left pane and workspace item shortcuts.

## Install

Open a `.user.js` file in Tampermonkey, then save it as a new userscript.
